## 保留与修正

保留状态随用户动作变化、错误说明可恢复、视觉图形与真实热区分开、消息形式对应任务关系。工程化为事件/状态/反馈/允许操作/恢复的映射。

不沿用固定颜色、透明度、状态数量与时间阈值：加载不一定用骨架，失败不能总是重试，重要错误不应两秒即消失；已有有效默认值不一定要清空成“请选择”。Web 点击目标用 CSS px 和 WCAG 条件判断，不把移动平台 pt/dp 互换；保留可访问标签而非只写 placeholder，并补上来源按钮清单遗漏的键盘焦点。

去向：[ui-interaction-checkpoints](../skills/ui-interaction-checkpoints/SKILL.md)。控件和反馈参考分别保存实际检查及一手依据，核验包括 WAI 控件标签/表单通知、APG Combobox/模态和 WCAG 2.5.8。键盘、状态竞态、焦点恢复等工程检查是整理者补充，不是原文已验证的项目结果；未进行真实页面或读屏测试。
