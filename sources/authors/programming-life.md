## 筛选口径

优先保留能明确回答“开发什么功能时用、如何选择、遗漏会怎样、如何验证”的内容。资讯、趣味排序、段子、榜单和无直接工程增量的推荐不进入技能。未完整读取的同主题内容仅视为合并候选，不能仅凭标题认定重复。

不按发布日期直接淘汰基础知识；与现行协议、库行为或项目条件冲突的说法要修正，无法核验的不纳入技能。本次已修正方法视频对 PATCH 幂等性的泛化，Git pull 的行为也不固定描述为只有 merge 一种整合方式。

后续只筛查有开发价值的未读内容，候选包括鉴权/SSO、API 网关与限流、CI/CD、容器部署、数据结构选择以及 CSS 动画；它们尚未因为标题相关就形成技能或结论。相应来源读取后才决定是否补充现有技能或新增。
