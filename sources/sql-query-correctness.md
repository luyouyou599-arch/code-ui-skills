## 合并提炼

概览提供 SQL 操作和连接类型的知识入口；工程落点是查询返回的业务对象是否正确，而不是会不会写语法。

- 列表和统计：先定义每一行代表谁，检查一对多 JOIN 是否放大行数。
- 需要保留无匹配主记录时：明确使用外连接的目的，验证条件放在 ON 与 WHERE 的差别。
- 分页：核对业务排序并提供唯一的排序次序；无确定排序时，不依赖某次结果恰好稳定。
- 执行 UPDATE/DELETE/DROP 等操作前：确认授权、目标和影响范围，不能将示意命令直接用于实际库。
