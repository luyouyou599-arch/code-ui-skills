# 依赖处理决策

- 前置关系明确且无环：可生成满足约束的拓扑序；无依赖的任务也要保留。
- 多个任务同时就绪：仅在资源与副作用允许时并行，不把无图依赖等同于没有共享资源冲突。
- 依赖不存在：明确是配置错误还是允许自动注册，不能隐式将错误拼写当新任务。
- 检测到环：输出涉及任务并停止生成“完整成功”结论；不要为获得顺序擅自删除业务依赖。
- 执行失败：明确何时释放下游，不能在入队或开始执行时就当作成功完成。

[Python graphlib](https://docs.python.org/3/library/graphlib.html)（2026-10-24 核对）给出 DAG、前驱映射、CycleError、get_ready/done 的语义；实际实现须适配项目语言、库版本与任务状态。特别注意该 API 的字典值是当前节点的前驱，不能直接套用相反方向的邻接表。
