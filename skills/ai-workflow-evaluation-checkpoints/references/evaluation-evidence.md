# 按任务选择评测证据

| 场景 | 关键决定与易漏项 | 验证证据 |
| --- | --- | --- |
| 问答或生成结果 | 输入之外明确期望事实、允许变化及拒绝条件；不只看语气或字符串相似 | 代表任务、缺失信息和错误前提；按业务规则检查结果或人工核对 |
| 检索增强功能 | 结果与检索分开判断，避免模型凭已有知识答对掩盖检索错误 | 核对实际检索片段、来源和访问范围；缺文档及无相关资料的分支 |
| 工具调用、多步流程 | 区分工具选择、参数、调用结果和实际副作用；必要步骤及终止条件应来自任务，不能照抄某次成功轨迹 | 查看调用记录与最终状态；无权限、依赖失败、重试及不应调用的用例，按当前实现选择 |
| 自动评分 | 先验证评分器是否能识别已知好/坏例；开放答案可有多种正确形式 | 用人工核对的正反例检查规则，记录分歧；评分失败与被测功能失败分别报告 |
| 修改提示、模型或数据 | 保持可比较的样本和规则，说明新增样本与版本差异 | 逐类比较结果、延迟和消耗；按风险与预算重复，记录失败和未运行项 |

代表性样本应依据实际任务；来源演示、训练用例和验收样本不是同一证据。用合成资料或已获授权且去敏的案例；测试数据之外的第三方资料不能自动公开。样本/阈值由功能目标确定，文档里的示例分数不能直接变成项目门禁。
