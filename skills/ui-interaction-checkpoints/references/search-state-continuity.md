# 搜索、筛选与排序衔接

用于当前功能涉及可展开搜索、异步建议、筛选面板或结果排序；读取实际查询条件、页面状态与接口行为，不因动效示例重建搜索架构。

| 使用场景 | 关键决策与易漏项 | 验证方法 |
| --- | --- | --- |
| 图标展开成搜索输入 | 展开后让焦点到可输入位置；决定关闭是否保留查询，关闭图形不自动等于清空已应用条件；给出可发现的清空/返回路径 | 键盘和触屏展开、Escape/返回、关闭后重开、移动软键盘；焦点不丢失，页面查询与可见条件一致 |
| 输入时更新联想 | 区分输入文本、键盘高亮、选中建议与已执行查询；建议更新不得静默改写用户文本或提交错误项。响应按查询版本对应，不能只靠视觉动画掩盖旧结果 | 中文输入法组合输入、快速增删、慢响应乱序、无建议、键盘确认与取消；选择对应当前建议的真实标识 |
| 筛选面板与滑块 | 先确定即时生效还是点击应用，区分草稿与当前结果；取消、重置各有明确对象，滑块数值与标签同步 | 修改后取消/应用/重置、无结果、越界和接口拒绝；重开条件与列表一致，键盘可调整。模态面板再按模态模式验证焦点 |
| 结果排序或布局重排 | 排序值、真实数据与视觉顺序一致；用稳定对象标识保持选择和对象身份，不用数组位置代表业务对象。只有顺序变化才考虑移动动画 | 同值稳定排序、快速换序、旧响应晚到、点击重排中对象、加载更多后排序；确认打开/操作的是选中对象而非旧索引 |

动画可帮助理解变化，但不应延迟输入、偷走焦点或成为理解结果的唯一方式。尊重减少动态效果设置，减弱或取消非必要大范围移动后，查询、选择和结果仍应可用。空结果/错误/后台刷新按实际状态显示，不将搜索失败误报为“没有内容”。
