# 控件状态与命中区域

| 场景 | 关键决策及易漏项 | 验证方法 |
| --- | --- | --- |
| 按钮与提交 | 区分默认、聚焦、悬停、按下、禁用及处理中；焦点不依赖 hover。选择禁用还是允许取消，说明被阻止的原因，处理中保留操作名称并避免布局跳动 | Tab 到达、Enter/Space 激活、鼠标离开、连续激活、成功/失败后恢复；确认表单中的非提交按钮不会误提交 |
| 触屏小图标 | 视觉图形和真实命中区域分开设计，扩大区域不能覆盖邻近控件；尺寸按平台、任务频率和密度确定 | 测实际点击框与相邻间距，触屏边缘点按及键盘焦点。WCAG 2.2 AA 的网页标准为至少 24×24 CSS px 或满足规定例外，不能把 iOS pt、Android dp 与 CSS px 混成一套硬指标 |
| 输入与校验 | 提供关联的标签，placeholder 仅作示例；保留规则说明，错误说明问题与改法。何时校验取决于输入过程，避免输入尚未完成就报错 | 空值、粘贴、中文输入法、聚焦/失焦、错误修正、提交服务端错误；错误与字段可关联，不能仅用红边；清空按钮有名称且清空后焦点合理 |
| 选择与联动 | 按需求决定默认值，确需主动选择才用未选态；区分当前选中与键盘高亮。是否搜索由选项可辨认度、规模与任务决定，不固定十项阈值 | 原生 select 优先；自定义组件按对应模式验证方向键、确认、Escape、焦点、选中语义；测试无结果、禁用原因、异步加载，以及上游改变后旧值是否失效 |

颜色加深百分比、透明度、缩放幅度及 44/48/8 等来源数字只作案例。禁用样式仍需能解释功能；`aria-disabled` 不会自动阻止事件，是否用原生 disabled 取决于组件语义。按钮加载状态不能证明服务端防重。

核验于 2026-10-24：[WCAG 2.5.8 点击目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)、[WAI 控件标签](https://www.w3.org/WAI/tutorials/forms/labels/)、[APG Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)。最后一项只用于确实实现 combobox 的控件，不将菜单、列表框与选择框混为同一组件。
