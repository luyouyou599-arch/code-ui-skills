# 表单与加载过程的连续性

仅在当前页面有相应功能时选择条目；基本标签、按钮和错误状态仍见各自参考，不重复建立所有状态。

| 场景 | 关键决策和易漏项 | 验证方法 |
| --- | --- | --- |
| 停止输入后或远程校验 | 明确输入中、失焦、提交时的校验职责；输入法组合期间避免过早判错，防抖不解决旧请求晚到的问题 | 连续输入、中文输入法、快速修改、失焦后提交；迟到结果不能覆盖新值，发送到服务端仍需校验 |
| 浮动标签与成功勾 | 标签在已填、自动填充和聚焦时仍可识别；格式正确、远程校验成功与业务提交成功分开 | 粘贴、浏览器/密码管理器填充、清空再填；勾与文案语义吻合，不遮挡实际值 |
| 验证码视觉分格 | 先定义真实输入语义，再选择单字段视觉分格或多字段；支持粘贴、删除、替换和适用的 one-time-code 自动填充 | 整码粘贴、部分替换、退格、读屏/键盘、超时与错误；位数满足不等于认证成功，自动发起也要等待实际校验结果 |
| 密码强度或星级评分 | 提示应服务规则与选择，不只用颜色、动画或拖动表达；优先成熟控件与可访问名称 | 密码提示不记录/回显敏感值，前后端约束一致；评分支持点击与键盘，显示当前值；不能用颜色升绿证明安全 |
| 图片/骨架转真实内容 | 按真实比例/尺寸预留区域，骨架只覆盖待获取内容；模糊是视觉策略，预占空间才处理该类布局位移 | 不同图比例、慢网、失败图与字体变化；用实际布局记录观察位移，不只看动效顺滑 |
| 提前获取下一页 | 根据速度和数据成本决定预取距离；有 in-flight/结束/失败状态，查询条件变化时隔离旧页 | 快速触底、重复触发、失败重试、空/末页及筛选切换；保持稳定标识，不重复追加，不把旧查询页混进新结果 |
| 开关/点赞/提交变形 | 区分期望状态、进行中和已确认状态；乐观更新有回退，连续切换需处理响应先后 | 快速多次激活、失败、旧响应晚到和重新进入页面；按业务权威状态核对结果 |
| 长按确认 | 明确开始、进度、中止与实际执行时机；保留不依赖精确持续按压的可用操作路径，避免按下即执行不可撤销动作 | 中途松开、移出、pointercancel、失焦/页面隐藏、键盘路径和重复触发；取消后不能残留计时器继续执行 |

相关核验（2026-10-24）：[MDN autocomplete](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/autocomplete) 包含 one-time-code 等含义，是否实际填充还取决于浏览器和平台；[web.dev CLS](https://web.dev/articles/optimize-cls) 讨论图片尺寸和动态内容导致的位移；[WCAG 指针取消](https://www.w3.org/WAI/WCAG22/Understanding/pointer-cancellation.html) 关注防止/取消误触；[WCAG 颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) 要求不能仅靠颜色表达信息。
