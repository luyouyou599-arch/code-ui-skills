# 操作反馈与确认的真实性

| 使用场景 | 关键选择与易漏项 | 验证方法 |
| --- | --- | --- |
| 复制按钮变勾 | 等实际复制操作成功再显示已复制；处理权限、上下文限制与失败，恢复时长按任务确定。装饰勾不能与成功事件脱节 | 模拟写入成功与失败，检查反馈和可重试路径；保留按钮可访问名称，不能仅改图形 |
| 加购飞入 | 动画可表达物品去向；若乐观展示，明确失败时回退和数量修正。动画结束不等于业务成功 | 请求拒绝、连续点击、迟到响应及库存变化；检查购物车数量与最终服务端结果一致 |
| 播放/暂停变形 | 图标及可访问名称表达当前允许的动作，实际播放失败或外部暂停也需同步 | 实际媒体状态、播放失败、键盘和重复操作；不能只切图标却没有对应行为 |
| 悬浮按钮展开 | 展开项需要可发现的名称、合理焦点顺序和关闭路径；逐项动画不应让不可见项目先获得焦点 | 展开/收起、点击外部、键盘与窄屏；按实际组件模式定义交互，不默认所有展开项都是菜单 |
| 危险操作确认 | 清楚表达动作和对象、是否可撤销及后果；遵循目标平台惯例和组件库。左右位置、颜色、宽度比例没有跨平台唯一值 | Enter/Space、初始焦点、取消与关闭、成功与失败；不可逆操作考虑把初始焦点放在较安全的选择，避免焦点默认触发危险动作 |
