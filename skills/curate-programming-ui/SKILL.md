# 编程与 UI 资料整理

把来源中的知识转化为开发中可调用的决策与检查方法，并支持基于实际项目证据拆解核心功能。默认使用中文，保留代码、API 名称与必要英文术语。

## 定位与读取

先定位用户指定的技能库；本技能随库分发时，先解析本技能目录的符号链接得到真实路径，库根目录为真实技能目录的 `../../`，不要相对于当前项目或全局链接目录计算。读取库的 README 索引和相关主题的已有资料、技能，判断是补充还是新增。未指定位置且无法定位现有库时，再确认保存位置。

分类、笔记字段与技能整理标准见 [references/library-format.md](references/library-format.md)，首次入库或调整结构时读取。

读取用户提供的来源正文。文章区分作者观点、引用材料与示例；视频区分字幕、音轨和画面，记录实际读取范围及可用的时间戳。标题、简介和搜索摘要只用于定位，不能当成完整内容。无法读取时说明缺失内容，请用户补充可访问正文、字幕或文件；在补齐前仅记录待整理条目，不生成该来源的内容结论。

## 提炼与判断

先筛选与开发决策、功能正确性或项目机制拆解直接相关的内容。资讯、段子、无应用条件的推荐不进入主题技能；重复资料只保留有增量的案例或修正。同主题只是候选合并依据，未读取前不能声称内容重复。发布时间不单独决定是否过时：结合当前官方依据和项目环境检查；不适用的旧方法不沿用，无法核验的建议暂不纳入技能。无需为覆盖作者全部作品而填充低价值内容。

- 提取核心概念、适用问题、前提条件、具体做法、示例及常见错误；按资料价值选择内容，不凑数量。
- 将重要知识映射为“何时相关 → 需要作出的选择或检查 → 遗漏的具体影响 → 实现位置与验证证据”。判断它影响哪个功能、开发阶段或模块边界；无法形成实际应用的内容先保留为参考笔记。
- 区分来源陈述、已验证结论、整理者推断与待验证事项。改写归纳，不复制大段原文。
- 技术性结论若涉及当前版本或存在疑点，查阅官方文档或一手来源核对；记录核对日期和适用版本。没有实际运行过的代码，不标为运行验证通过。
- UI 内容分清视觉偏好、设计原则和有证据支持的可用性结论。保留平台、用户群、任务和界面状态等适用条件；不把单个案例升格为通用规范。
- 用户对协作方式的提醒落实到整理行为，不转写成技能库的主题知识、界面文案或案例。

## 整合为技能

先写来源笔记，再判断是否已有足够材料支持可重复执行的任务。纯概念或证据不足的资料先保留为笔记，并简述尚缺什么。

以任务而非文章标题划分技能。优先更新已有技能；只有任务、触发场景或工作流程实质不同才新增。存在矛盾时保留各自适用条件及未解决的问题，不强行合并。

主题技能必须说明何时使用、需要哪些输入、关键决策或操作、如何检查结果及适用边界。将长案例、版本细节和来源映射放入技能自己的 `references/`，从 `SKILL.md` 链接，保证单独迁移时仍可理解。需要保留来源笔记关联时，同时保留原始 URL 和引用位置。

主题技能默认服务两类任务：开发或评审核心功能时选择相关检查点并落实；阐述项目时从真实需求、代码和验证记录提取核心机制、设计取舍及模块关系。知识讲解是参考材料，不作为默认技能的最终任务。说明工程应用推导与原作者结论的区别，必要时补充一手依据。

开发检查只选择与当前功能有关的要点，按遗漏影响与成本排序，不把整库变成所有项目的必做清单。项目阐述不能将浏览器或框架默认提供的能力冒充项目成果，不编造未实现机制或未测量收益。

主题技能面向跨项目复用，不写死具体项目目录、品牌、业务数据或某次对话的临时要求；执行时读取目标项目的规范与上下文。此资料整理技能负责维护统一资料库，主题技能执行时不依赖读取整库。

不在所有任务中强制加载整个库；通过准确的技能描述和按需读取参考资料控制上下文。避免把通用常识、原文全文和无关工具规则塞进技能。

## 保存与交付

保存笔记，新增或更新技能，再同步库索引。索引只记录已实际写入的内容；更新已有内容时保留仍有效的来源及条件。

检查链接、相对路径、技能 frontmatter 和是否残留模板占位。环境提供 skill-creator 校验器时运行结构校验；结构通过与行为验证分开记录。只有实际试用后才描述试用结果。

用户选择本机跨项目复用时，完成结构检查的本库技能在用户级 `~/.agents/skills/<skill-name>` 建立指向库内真实技能目录的符号链接；仅处理本库技能，遇到同名且指向其他内容的目录或链接时先报告冲突，不覆盖。现有链接正确时无需重复创建。目录写入仍遵守当前执行权限；受限时如实报告未安装，不能把文件已保存当作安装成功。

向用户简要报告分类、关键收获、新增或合并的内容、保存位置及影响使用的未验证事项。持续整理与本机安装遵循用户的已有授权，不据此自动抓取其他资料、发布内容或同步其他设备。只有用户已授权的内容才推送公开仓库；不要将本机绝对路径、凭据或私人资料写入公开文件。
