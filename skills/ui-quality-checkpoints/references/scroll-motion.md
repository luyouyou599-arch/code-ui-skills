# 滚动与展示动效的设计约定

用“触发 → 目标元素 → 起止值 → 时间或滚动进度 → 重复/退出 → 降级”描述效果。比如进入视口的渐显，应明确播放一次还是再次进入重放、内容何时可见、减少动态效果时如何直接显示；具体距离和时长由布局、内容与设备确定。

| 功能意图 | 候选方式 | 易漏项与验证 |
| --- | --- | --- |
| 内容分组出现 | 淡入、滑入、交错、遮罩 | 正文和链接在脚本失败、慢加载、深链接直达时仍可访问；键盘焦点不能落在不可见内容。按 reduced motion 移除不必要运动 |
| 展示进度或当前章节 | 滚动监听、文字填充、线条描画 | 区分装饰和真实状态；读屏需要稳定的文本及必要语义。验证跳转、快速滚动、返回恢复与视口改变 |
| 产品故事与空间层次 | sticky、视差、卡片堆叠、横向叙事 | 检查 sticky 容器和滚动范围、窄屏顺序及焦点不被覆盖；不为效果锁住正常浏览。优先考虑普通流布局的替代 |
| 序列帧或局部微动效 | 产品转动、角色引导、图表增长 | 帧资源大小、解码与内存成本先估算再实测；保留静态海报/最终数据，不能用动画伪造真实业务增长 |

进入/离开视口的阈值观察可考虑 IntersectionObserver；它不直接提供精确的逐像素滚动进度。选择 CSS 或脚本动画依赖目标浏览器支持及效果，不默认安装大型库。清理组件卸载后的观察器/监听器，实际比较动画开关前后的流畅度和资源使用；没有测量不宣称更快。

2026-10-24 核对：[MDN Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)、[减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)。
