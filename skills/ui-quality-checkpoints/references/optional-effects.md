# 可选视觉效果的选择与降级

以下是沟通效果的词汇，不是高质量界面的充分条件。适用判断和验证为整理者推导。

| 候选效果 | 可能适用 | 选择条件、易漏项与验证 |
| --- | --- | --- |
| 三维倾斜、聚光灯、磁吸按钮、光标拖尾 | 作品展示或轻量品牌反馈 | 不挪走可点击目标，不替代系统光标和键盘焦点；触屏无需依赖 hover。验证命中区域、离开恢复及滚动性能 |
| 毛玻璃 | 叠层、浮层的材质区分 | 模糊后背景仍会变化，须检查文字对比与不透明回退；在实际低性能设备检查滚动与渲染成本 |
| 便当盒布局 | 不同优先级内容的分组呈现 | 它是布局结构；卡片大小应体现内容关系。检查窄屏阅读顺序、长内容和 DOM 顺序，不为凑格子切碎任务 |
| 极光背景、流光边框 | 局部品牌氛围或强调 | 保持内容和状态清晰；避免持续装饰动画争夺注意。对比开启/关闭后的可读性和性能，减少动态效果时提供静态样式 |
| 新拟态 | 特定品牌下的少量材质表达 | 不只靠低对比阴影标识控件或状态；检查边界、焦点与禁用状态是否可辨 |
| 乱码解码、卡片翻转 | 标题展示或次要信息揭示 | 重要信息可直接访问；读屏可获得稳定文本，不能把乱码逐帧播报。翻面内容需可通过键盘和触屏到达 |
| 点击涟漪 | 操作的局部即时反馈 | 不能代替提交成功/失败状态；检查重复触发、键盘反馈及减少动态效果时的替代 |

与动效相关的功能需尊重 [prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)，减少、移除或替换非必要运动。CSS 回退、键盘与触屏方案仍需在目标项目验证。具体时长、模糊半径和动画实现不从演示画面直接推定为最佳值。
