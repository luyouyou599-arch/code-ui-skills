# 内容密度与显示稳定性

| 使用场景 | 关键选择与易漏项 | 验证方法 |
| --- | --- | --- |
| AI 生成页面解释过多 | 逐条判断文案帮助识别、选择、填写、恢复还是解释已显然的信息；删合重复内容，保留影响用户选择的必要条件与风险说明 | 用真实任务走页面；检查删后是否仍能识别动作、理解约束并从错误恢复；不能只按字数判质量 |
| 倒计时、金额与变化数字 | 当数字变化会导致横向跳动时，考虑支持 tabular-nums 的字体特性和合适宽度。等宽数字不等于整段使用等宽字体，位数、符号和小数点仍可能变化 | 验证实际字体/后备字体，1→8、9→10、负号、单位和本地化格式；无跳动且不裁切。不要给所有正文强制等宽 |
| 流式回答或持续内容 | 将接收数据、逐步显示、最终完成、中断/失败分开。滚动策略尊重用户正在回看的位置；读屏避免逐字重复播报，减少动态效果时仍能及时读到内容 | 慢速、快速、长内容、取消与中断；用户滚离底部后不要强拉回，恢复阅读或回到底部的路径明确。装饰显现不能隐藏已可用内容 |
| 精简边框与主题字重 | 表面分层可以减少无意义装饰，但控件识别、焦点与状态不能只靠极小亮度差；深色减字重取决于字体、尺寸和渲染 | 实际主题、显示缩放及字体检查文字可读与控件可辨；保留识别必需的边界，不把无边框当高级的充分条件 |

## 按任务安排操作层级

在结算、提交或重要确认页，先列出用户当前需要核对的对象、金额、时间等事实，再决定主操作与次要内容的权重。促销、会员、推荐可按场景收起或降低层级，但不能连必要确认信息一起删掉。界面简洁程度不按元素数量判断。

验证真实任务下主操作是否易辨认，必要条件是否仍可见，展开细节与窄屏内容是否遮挡主操作；不能以视觉检查声称转化率提高。网络媒体 [结算页操作层级](https://www.xiaohongshu.com/explore/6ad8ad3d0000000024034b92)，2026-10-24 完整配文已读，视频未完整读取；以上验证为工程补充。
