# 图标、字重与视觉角色

当页面存在图标/文字角色漂移，或收到“更高级”这类抽象视觉目标时使用。先复用目标项目的设计变量，检查真实页面，不按下面的例子重建全套品牌。

| 决策 | 遗漏的影响 | 验证方法 |
| --- | --- | --- |
| 按语义角色定义图标容器和尺寸，再核对可见路径、描边、基线及视觉重量 | SVG 画布相同但路径比例不同，一排图标仍忽大忽小；直接放大图标会把行高或热区挤坏 | 对照同类导航/工具栏/文字旁图标，检查实际 SVG viewBox 与渲染；光学校正允许例外。图形尺寸与可点击范围分开检查 |
| 图标承担动作时提供可访问名称；与旁边可见标签重复且无附加信息的装饰图标避免重复朗读 | 只有图形可见，辅助技术不知道动作；同一按钮被重复读出 | 查看可访问名称并实际操作；名称表达“搜索/保存”等用途，不只说“放大镜/磁盘” |
| 字重配合字号、行高、分组与对比形成角色；核对实际字体和回退 | 指定了字体没有的字重，换设备或字体加载失败后层级变化；过度减淡辅助信息造成不可读 | 正文/标题/按钮及混排样本，目标设备、字体加载前后与放大结果；不强制全页只用两档字重或最少 1.5 倍字号差 |
| 将视觉目标具体化为主次、密度、对齐或装饰取舍，按任务比较方案 | 机械降低饱和、删线、加留白，破坏数据密度、状态识别或品牌 | 使用相同真实内容对照核心任务；必要时做实际可用性验证，不能由风格推断业务收益 |

16/20/24/32 图标和 60/30/10 面积仅是来源案例。颜色状态不能仅靠色相区分；同尺寸图标也不是同热区。间距与嵌套圆角继续按现有视觉参考核对，不新增第二套数值规范。
