# 身份、会话与访问权限检查

先读取实际登录方式、身份提供方、后端中间件、受保护资源和用户/租户关系。区分“是谁”“可操作什么”“登录状态何时失效”。没有真实项目材料时给出候选检查点与缺失证据，不断言存在漏洞。

按 [references/decisions.md](references/decisions.md) 选取当前功能需要的条目。先复用项目现有身份库与权限机制，确认信任边界及令牌验证责任。令牌格式、认证方式和资源授权是不同决策；不能仅因 JWT 可解码或前端显示已登录，就认为受保护操作可访问。

在授权环境中验证正常身份、未登录、过期身份、错误资源归属及角色变化后的结果。检查服务端实际返回与持久化副作用；隐藏按钮仅影响交互，不作为授权证据。不得使用真实第三方账号或生产权限做越权实验。

涉及 SSO 时区分身份提供方会话、各应用本地会话及协议令牌的作用，核对回调与应用权限。若缺少提供方配置或协议细节，先标出待验证点，不能按概览图自制协议实现。

项目阐述时从实际登录/访问链路说明身份由谁确认、权限在哪里判断、会话如何失效、采用现有方案的理由与代价。只陈述已实现和已验证的能力，不因使用某个认证产品就宣称实现了所有安全能力。
